# Project rules from the user

- No generative AI pictures anywhere in this project, including the app, demos, documentation, maps, portraits and promotional material. Do not call image-generation tools. Use user-provided assets, licensed existing artwork, text, simple shapes and code-native interface icons.
- Do not generate voices. NPC voice suggestions are written roleplay tips only.
- D20 rolls must remain fair and surprising. Do not weight natural 1s or 20s, script criticals or alter results to manufacture drama. Highlight exceptional results only when the actual roll produces them. Normal advantage uses two fair dice and keeps the higher.
- Core tools must remain useful without an AI subscription. AI text assistance, if added, is optional.

- Beginner clarity: use plain language, show the next step, explain required fields and consequences, clearly identify examples and unimplemented features, and protect saved work from accidental replacement. Keep help specific to the current task and use respectful language.
